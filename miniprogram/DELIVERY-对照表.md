# 交付对照表（DoD · 移植验收清单）

这份表把 **PRD 附录 B 的 MVP 交付清单**与 **移植指南第十节的验收清单**逐条对到实现与断言上，
用来回答一个问题：**「说做了」和「真的做了」是不是同一件事。**

- 位置一律写成「文件 + 函数名」，便于核对；
- 断言名写在 `_smoke_s1.js` 里，跑 `node _smoke_s1.js` 就能复核；
- 状态只有三种：**已完成**、**部分**（写明缺哪一半）、**未做**（写明卡在哪）。

最后一节列出**本机无法验证**的部分，那些条目即使标了已完成，也只是「代码在此」，不是「真机通过」。

补充说明（这轮改了数据结构）：`spent` 原本是一个数字，两台设备各自离线兑换 20 分会合并成
20（少算一次）。现在兑换记成**只增不改的 `redemptions` 明细**，`spent` 由明细求和派生，
合并 = 两条明细取并集。老数据在 `load()` 里补一条迁移明细，余额原样接住。
签名与生效状态**取较严的一方**，避免「一边没签、同步完就生效」。

### 第 9 条：为什么现在算完成了
上一轮我把它标成「未做」，理由是「埋点要落库」。这一轮改了判断：PRD §10 要的是**指标覆盖**
与**一键导出/删除**，而 §7 非功能需求里「支持一键导出/彻底删除」是**硬要求**，不能等云环境。
所以拆成两半分别处理：

- **指标**：`metrics()` 是纯函数，口径逐条写进 `METRIC_DEFS` 并导出。接上任意分析后端时
  这个结构就是可直接上报的字段表，不用重写；本机也能在「我的」页给她自己看。
  **未做**的只是「上报通道」（需要真实 AppID 与云环境）。
- **导出 / 删除**：`exportAll()` 导出全量 state（深拷贝）+ 指标；`wipeAll()` 用 `blank('mid')`
  重建状态，删除后回到「第一次打开」并由闸门接管。UI 两道确认，第二道显式问「备份过了吗」。

**与「家长不可删除」的红线不冲突**：那条约束的是**家长**（PRD §1.4 红线 3、§4 M4）；
这里是**数据主人自己**行使 §7 的删除权利，主体不同。有断言守着家长端
仍然没有任何删除接口（`deleteEntry` / `deleteCoupon` 等都不存在）。

PRD 只说「Excel 导出」，没说格式。本工程输出 **CSV**：纯文本、Excel / WPS / Numbers 双击即开、
带 UTF-8 BOM 与字段转义、不需要后端。若要真正的 `.xlsx`（多 sheet、带格式），
那属于服务端 / 云函数职责，`buildLedgerCsv()` 的取数逻辑可以直接复用。

### 第 6 条：为什么「只能升不能降」没有强制

PRD 与验收清单都写了「学段只能升不能降」，但**没有说明遇到降级请求该怎么办**：
是直接拒绝、还是允许但要二次确认？这属于产品决策，不该由实现擅自拍板。
目前 `applyStage` 对任何目标学段都执行（升、降、同级都行），并把后果交给她与家长
（换学段 = 重新定规则 + 重新双签，代价已经很高）。
**要改成硬拒绝只需要在 `applyStage` 开头加三行**，但那要先确认产品意图。

### 第 8 条：离线可用但没有测量

「≤ 5 秒 / ≤ 2s」需要在真机上测（并有真实数据量）。本工程能确证的只有一件事：
**计分路径完全不依赖网络**，所有读写都走 `wx.setStorageSync`，所以离线打卡在结构上成立。
真实耗时必须真机测量，见下节。

## 三、本机无法验证的部分

这些条目**即使标了「已完成」也只是代码在此**，不是真机通过。本机没有安装微信开发者工具
（`C:\Program Files\Tencent` 下只有 Weixin 与 WeType），也没有真实 AppID / 云环境：

| 项 | 为什么做不了 |
| --- | --- |
| WXSS 是否被编译器接受 | 需要开发者工具编译；本工程只能按规则扫关键词 |
| WXML 标签与表达式校验 | 用的是自写的启发式解析器（已踩过一次 `<br>` 空元素误报），不是官方编译器 |
| 视觉与布局 / 触摸目标手感 | 需要模拟器或真机 |
| 云数据库的**真实**读写、索引、性能 | 代码层的集合定义与安全规则已可回归（`[D]` 段），但真实建库、配额、并发都要云环境 |
| 基础库低版本的真实表现 | 降级路径已按接口版本表写好并有断言（无 `getWindowInfo` → `getSystemInfoSync`），但真机上是否还有别的差异要实测 |
| `wx.cloud.init` 与真实鉴权（`auth.openid`） | 需要真实 AppID 与云环境；适配器已按「没有 `wx.cloud` 就降级」写好 |
| `canvas 2d` 同层渲染、`dpr` 取值、老基础库降级路径 | 需要真机与不同基础库版本 |
| `wx.showModal` 的 `editable`、`wx.setClipboardData`、`wx.reLaunch` 的真实时序 | 需要在真实宿主里跑 |
| 性能指标（打卡 ≤ 5s、首屏 ≤ 2s） | 需要真机与真实数据量 |
| 云数据库集合、安全规则、云函数、服务端 PDF | 需要真实 AppID 与云环境；**集合定义与安全规则已在代码层完成并回归**（`cloud/`） |
| 上传、分包、隐私指引配置、监护人同意 | 平台侧流程 |

`project.config.json` 与 `project.private.config.json` 已就位，在有开发者工具的机器上
「导入项目」即可；`README.md` 第五节列了接手后的 7 步验证顺序。
