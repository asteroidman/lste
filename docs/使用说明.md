# 罗森塔尔 · 家庭版使用说明

> 写给孩子身边的家长：这是一张**会说话的电子打卡纸**。
> 孩子每做到一件小事，就记下来、给一句具体的话、攒一点分，攒够了换她真正想要的奖励。
> **只加分，没有扣分；所有数据只存在这台设备里，不联网、不上传、无账号。**

---

## 一、安装

| 方式 | 步骤 |
| --- | --- |
| Android 安装包（推荐） | 拿到 `罗森塔尔.apk` → 点开安装（提示「未知来源」时允许；小米/华为需临时关「纯净模式」） |
| 电脑 / 平板浏览器 | 直接用浏览器打开 `罗森塔尔.html` 这一个文件即可，功能完全一样 |

- 支持 Android 5.1+；平板、手机通用
- App **不申请任何权限**，系统层面保证不可能联网
- 升级新版本：直接安装新 APK 覆盖，**数据保留**（前提：一直用同一来源的安装包）

---

## 二、第一次使用（约 1 分钟）

1. 打开 App → 选她的学段（小学低段 / 小学高段 / 初中 / 高中）——每个学段自带一套适龄的规则模板；
2. 给她起个称呼（默认昵称也可以）→ **开始使用**；
3. 结束。就这么简单，规则已经按学段配好了，之后随时可以改。

---

## 三、每天怎么用（「今日」页）

- **她做到了** → 找到那件小事 → 点「**记一笔**」。
  系统会自动附一句具体的肯定（比如「我看到你连续读了 30 分钟」），不是干巴巴的 +1。
- 家长也可以点「**代记**」（需要家长密码）——比如她做完才告诉你的时候。
- **记错了** → 流水里 24 小时内可「**撤销**」。历史不会消失，只会打上「已撤销」的标记，谁也改不了账。
- 页头能看到：今日 /12（每日上限）、连续天数、累计、可用积分。
  每日上限是刻意设计的——**积分不该刷爆，够用就好**。

> 小提醒：与其晚上一次性补记 5 件，不如当场记 1 件。「被看见」发生在做到的那一刻才最有效。

---

## 四、积分与奖励（「奖励」页）

- 页首大数字是**可用积分**；
- 奖励按档位排好（亲子 / 物质 / 娱乐 / 特别 / 大奖励），点「**兑换**」→ 扣掉积分、发一张券；
- **券 30 天内有效**，用掉或过期都不退分——这是「说话算数」的练习，兑换前会再确认一次；
- 想 改内容 / 改分值 / 移除 / 加一档 → 都可以，但需要**家长密码**（见第六节）。

> 建议让奖励清单里有 2–3 个「不花钱」的：周末晚睡 30 分钟、和爸爸单独约会、决定一顿晚饭……关系本身就是最好的奖励。

---

## 五、每周固定动作（「周复盘」页）

- 一页看到：本周积分、有记录的天数、连续天数；
- **周结算**（需家长密码）：按表现发周奖励分——
  - 周达标（本周 ≥ 50 分）**+10**
  - 连续 7 天有记录 **+10**
  - 主动挑战 **+5**
- 可以把这一周的亮点整理成「**一周一页**」打印出来贴在冰箱上；也可以把周目标写下来，下周接着看。

---

## 六、家长密码（PIN）

- 改规则、改奖励、周结算、代记、导出备份、换学段 → 都要输入 **4–8 位家长密码**；
- **孩子日常打卡、兑换、用券、打印不需要密码**；
- 首次设置时会生成一个 **`LST-XXXX-XXXX` 恢复码**——抄下来收好，忘了密码靠它找回（只显示这一次）；
- 都在「家长」页里管理：设置 / 修改 / 用恢复码重置。

---

## 七、打印（免密）

「家长」页提供三种打印模板，点击后用系统打印（可存 PDF）：

| 模板 | 用途 |
| --- | --- |
| 今日卡 | 当天的清单 + 具体反馈，贴书桌前 |
| 规则表 | 一张 A4 看懂全部规则，全家对齐 |
| 一周一页 | 周复盘版面，含她签名位 |

> 没有打印机的家庭：存成 PDF 发到微信，或直接给娃看手机屏幕，效果一样。

---

## 八、备份与换手机（重要！）

数据只存在这台设备里，所以：

- **定期导出**：「家长」页 → 「全量备份 JSON」（需密码）。超过 7 天没备份，App 会提醒你；
- **恢复**：新设备装好后 → 「选择备份文件」→ 导入，记录、积分、规则全部回来；
- **换手机** = 旧机导出 + 新机导入，两步；
- 卸载 App、清除应用数据、恢复出厂都会清掉本地数据——**没有备份就真没了**，请像存照片一样对待备份。

> 导出的 JSON 可以发到微信「文件传输助手」或存网盘，它只是一份文本文件。

---

## 九、隐私与边界

- **零联网**：App 没有 INTERNET 权限，也不可能上传任何数据；
- **零账号**：没有注册、没有登录、没有统计；
- **不可改账**：流水只能撤销（打标记），不能删改；积分只能加分，系统里不存在减分；
- 给孩子的保护：她改的内容会标注「自己改的」，家长代记会标注「家长代记」——账目透明，互相看得见。

## 十、常见问题

| 现象 | 处理 |
| --- | --- |
| 打开是白屏 | 重新下载安装包；或确认打开的是完整的 `罗森塔尔.html` 单文件 |
| 忘了家长密码 | 「家长」页 → 用恢复码 `LST-XXXX-XXXX` 重置 |
| 恢复码也丢了 | 无法找回 PIN；用「恢复备份」导入一份**设密码之前**的备份即可绕开 |
| 想从头开始 | 「家长」页 → 清空所有数据（需密码，操作前会先提示你导一份备份） |
| 换浏览器 / 换设备看不到数据 | 正常——数据在原设备的存储里，用「全量备份 JSON」迁移 |
| 打印没反应 | 手机上选择「打印 / 另存为 PDF」；电脑上直接 Ctrl+P |

## 十一、一句话理念

> 「每天看到做到的小事，人就会朝被肯定的方向长。」

这张纸不评价她是谁，只记录她今天做到了什么。
坚持一个月，你大概率会看到：不是她变了，而是你们的对话变了。

*祝你们用得开心。有任何问题，随时反馈给作者。*
