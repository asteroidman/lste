# 罗森塔尔 · 单文件家庭版

一个 HTML 文件就是一个完整产品：**零安装、零联网、零账号**。数据只存在这台设备的浏览器里。

## 怎么用

1. 把 `罗森塔尔.html` 拷到电脑/手机（微信「文件传输助手」发给自己，下载后用浏览器打开也行）。
2. 用 **Chrome / Edge** 双击打开（手机上用系统浏览器打开该文件）。
3. 第一次打开：选学段 → 填昵称 → 开始。规则表按学段自动生成，直接能用。
4. 五个标签页：**今日**（打卡/撤销/闪光点/券包）· **规则**（改分值/增删项）· **奖励**（兑换/改档）· **周复盘**（结算/打印）· **家长**（密码/导出/恢复）。

## 家长密码

- 修改类操作（改规则、改奖励、周结算、代记、导出备份、换学段、清空）需要 **4–8 位数字密码**；孩子日常打卡、兑换、用券、**打印**都不需要。
- 首次设置时会显示一组**恢复码**（形如 `LST-XXXX-XXXX`）——**抄在纸上**，忘了密码凭它重设；它只显示这一次。

## 备份（重要）

数据只在本机浏览器：清缓存、换设备、重装系统都会看不到。请在「家长」页：
- **导出全量备份 JSON**（修改数据后顺手做一次，超过 7 天没备份会自动提醒）；
- 新设备上**恢复备份**即可无缝继续。
- 也可导出**规则表 CSV**（Excel 打开）与**打卡记录 CSV**。

## 打印

三个版面都走浏览器打印对话框（可存 PDF）：**今日卡**（今日页）、**规则表**（规则页）、**一周一页**（周复盘页，含双签行与给家长手写的一句话）。

## 隐私

文件不联网、没有统计、没有账号。所有人的记录都在本地——包括「仅自己可见」的条目。

## 开发者

- 重新构建：`node single/build.mjs`（把 `miniprogram/utils/` 的引擎 + `single/src/` 的界面内联成一个 HTML）。
- 回归：`node single/_smoke.mjs`（82 项：构建产物 / 引擎 / PIN / 打印 / 红线词 / UI 接线 / **jsdom 真实点击链路**——学段选择→打卡→设 PIN→改分值→遮罩关闭全流程）。
- 改界面源码只动 `single/src/*`；引擎红线与小程序同源，**不要**直接改产物 HTML。
- 想要 Android 安装包：见 [`../docs/APK-构建与安装.md`](../docs/APK-构建与安装.md)（Capacitor + GitHub Actions 云构建，零权限、不上架）。
